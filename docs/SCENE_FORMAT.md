# Формат сцен

Сцена — это один файл на [ink](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md): диалог, свидание или событие. Текст пишется как обычный ink, а всё, что касается картинки, звука и игры, задаётся **тегами** — строками, начинающимися с `#`.

Это справочник. С чего начать, как подключить сцену к игре и как ставить катсцены — в [гайде сценариста](WRITER_GUIDE.md).

Сцены пишут в студии: «Сцены» на странице тайтла. Редактор подсвечивает ink и наши теги, подсказывает ключи тайтла, подчёркивает ошибки прямо в строках и показывает сцену в телефоне рядом с текстом (подробнее — в [гайде сценариста](WRITER_GUIDE.md#редактор-сцен-в-студии)). Вне студии удобно писать в [Inky](https://github.com/inkle/inky/releases): он ловит ошибки ink, но наших тегов не знает — их проверит сборка.

## Пример

```ink
# bg: gym
# music: upbeat
Вечерний зал почти опустел.
# show: anna neutral left
anna: Опять ты? Я начинаю думать, что это не совпадение.
# effect: flag met_anna
me: Может, и не совпадение.

* { has("water_bottle") } [Предложить воду]
    # effect: take water_bottle
    # effect: affection anna +3
    # show: anna happy
    anna: О, спасибо. Ты внимательный.
* [Пошутить про тренера] # effect: affection anna +1
    anna: Ха. Только не при нём.
* { affection("anna") >= 20 } [Позвать на кофе #premium: 15]
    # effect: affection anna +5
    # effect: start_quest anna_coffee
    anna: …Давай. Но платишь ты.

- anna: Ладно, мне пора. До завтра?
# hide: anna
-> END
```

Сцена начинается с первой строки файла и заканчивается на `-> END`. Узлы (`=== имя ===`) внутри сцены можно использовать как обычно: для веток и для запуска «с этого места» в превью.

## Реплики

| Запись | Что это |
|---|---|
| `anna: текст` | Говорит персонаж с ключом `anna`. Имя и цвет плашки берутся из реестра персонажей тайтла |
| `me: текст` | Говорит протагонист. Имя подставит игра |
| `текст` | Повествование, без плашки с именем |

Ключи пишутся латиницей в нижнем регистре: `anna`, `gym`, `water_bottle`.

## Теги сцены

Тег на отдельной строке относится к следующей реплике и срабатывает перед её показом.

| Тег | Пример | Что делает |
|---|---|---|
| `bg: <фон>` | `# bg: gym` | Сменить фон |
| `show: <персонаж> <эмоция> [left\|center\|right]` | `# show: anna smirk left` | Показать персонажа или сменить его эмоцию. Без позиции новый персонаж встаёт в центр, уже показанный остаётся на месте |
| `hide: <персонаж>` | `# hide: anna` | Убрать персонажа |
| `music: <трек>` или `music: stop` | `# music: upbeat` | Фоновая музыка |
| `sfx: <звук>` | `# sfx: door_slam` | Звуковой эффект |
| `wait: <секунды>` | `# wait: 1.5` | Пауза, до 10 секунд |
| `fx: shake` или `fx: flash` | `# fx: shake` | Встряска экрана или вспышка |

## Эффекты

Эффект меняет состояние игры. Он записывается тегом `effect:` и применяется сервером, когда сцена закончилась.

| Эффект | Пример |
|---|---|
| Симпатия персонажа | `# effect: affection anna +3`, `# effect: affection anna -1` |
| Характеристика | `# effect: stat charm +2` |
| Дать или забрать предмет | `# effect: give rose`, `# effect: take rose 2` |
| Поставить или снять флаг | `# effect: flag met_anna`, `# effect: unflag met_anna` |
| Квест | `# effect: start_quest anna_coffee`, `# effect: advance_quest anna_coffee` |
| Опыт аккаунта | `# effect: xp 10` |
| Достижение | `# effect: achievement first_date` |

Правила:
- **Знак обязателен.** У симпатии и характеристик пишется `+3` или `-1`, не `3`.
- **Только конкретные значения.** Переменные и выражения в тегах не работают. Сервер заранее знает полный список эффектов сцены и не примет эффект, которого в тексте нет.
- **Валюту и платные предметы сцена не выдаёт.** Их выдают только правила игры на сервере.

## Платный выбор

```ink
* [Позвать на кофе #premium: 15]
```

Тег `premium` пишется **внутри квадратных скобок**, тогда он относится к самому варианту, и игра покажет цену до выбора. Тег после скобок срабатывает уже после выбора: так пишутся эффекты варианта (`* [Пошутить] # effect: affection anna +1`).

Хотя бы один вариант в каждом выборе должен быть бесплатным.

## Чтение состояния игры

Сцена может проверять состояние игры. Объявлять функции через `EXTERNAL` не нужно, они доступны сразу.

| Функция | Что возвращает |
|---|---|
| `affection("anna")` | Симпатия персонажа |
| `has("rose")` | Есть ли предмет в инвентаре |
| `flag("met_anna")` | Стоит ли флаг |
| `stat("charm")` | Значение характеристики |
| `global_level()` | Уровень аккаунта игрока |

Функции видят эффекты, сработавшие раньше в этой же сцене: после `# effect: take water_bottle` вызов `has("water_bottle")` вернёт ложь.

Условие для варианта выбора пишется **прямо в выборе**, перед текстом:

```ink
* { has("water_bottle") } [Предложить воду]
```

Обернуть выбор в блок `{ has("water_bottle"): ... }` нельзя: ink выдаст ошибку компиляции.

## Что проверяется при публикации

- Ошибки ink, с номером строки.
- Неизвестные персонажи и эмоции, а также предметы, характеристики, квесты и достижения в эффектах.
- Фоны, музыка и звуки, для которых не загружен файл, — предупреждение: в игре будет заглушка ([ASSETS.md](ASSETS.md)).
- Неправильный формат тегов: например, симпатия без знака или неизвестный эффект.
- Переменные и выражения в тегах.
